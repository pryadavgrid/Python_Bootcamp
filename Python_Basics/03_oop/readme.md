This repository contains my practice and learning code for **Object-Oriented Programming (OOP) in Python**.
The main goal of this project is to understand core OOP concepts with simple examples and clear structure.

I have already completed the coding part, and this repository is created for **revision, practice, and future reference**.

### 6. Dunder (Magic) Methods

Special methods in Python that start and end with double underscores.

Covered dunder methods:

* `__str__` → String representation of an object
* `__len__` → Length of an object
* `__del__` → Called when an object is deleted
